## 🎯 Problema e Hipótese
*   **Dor:** Cronômetros online são complexos, poluídos e geram atrito cognitivo.
*   **Hipótese:** Um timer minimalista (apenas Iniciar/Pausar/Reiniciar) reduz distrações e aumenta o foco imediato.
